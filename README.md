# Strong Enough to Govern — Research Repository

Research and reproducibility materials for the book project **Strong Enough to Govern**.

This repository stores machine-readable coding, methodological protocols, source provenance, and computational materials used to test the book's institutional-design framework. It is not the book manuscript and does not treat design hypotheses as established empirical findings.

## Current research components

- comparative case coding for democratic erosion, resistance, reversal, and restoration;
- timing episodes where legal relief may arrive before or after practical irreversibility;
- canonical institutional options and dependency/common-mode-failure coding;
- structural state/local cases;
- source and provenance manifests.

## Analytical principles

The project distinguishes observable **entrenchment effects** from claims about incumbent motive; treats detection, adjudication/authorization, implementation/compliance, sanction, and replacement/restoration as distinct accountability functions; and evaluates safeguards on executive capacity, common-mode dependencies, cumulative threat-level resilience, and individual dependency sensitivity.

Comparative cases are used to test mechanisms, not to infer U.S. causal effects directly. Structural reforms are retained in the core argument only where evidence links them to accountability mechanisms or safeguard durability.

## Repository layout

- `data/` — coded research datasets and source manifest
- `schemas/` — canonical option and accountability-function definitions
- `docs/` — methodology, coding protocol, provenance, and research decisions
- `references/` — BibTeX metadata used by the research baseline

## Reproducibility

For derived results, record the source URL/DOI/archive identifier, retrieval date, source version/date, transformation script, output filename, manual coding decisions, redistribution status, and checksum when practical. Raw third-party sources should not be redistributed unless permitted.
