# Proposal-stage research status

**Originally dated:** 2026-10-02  
**Updated:** 2026-10-03

The pre-proposal research program is complete enough to freeze the working architecture for proposal preparation.

## Architecture result

The current framework uses six provisional protected function families: election finalization, bounded emergency authority, domestic coercive/military authority, neutral administrative capacity, timely oversight/records, and non-impunity clemency.

Domestic coercive/military authority was promoted from an omitted candidate after applying the same inclusion criteria: accountability consequence, concentrated chokepoint, time-sensitive reversibility, and a plausible capacity-compatible safeguard. Courts remain cross-cutting enforcement infrastructure; Senate/House/electoral-system rules remain structural reinforcement; civic norms remain civic reinforcement.

## Comparative and timing research

The proposal-stage comparative set is Brazil, Botswana, Poland, and Zambia under a common outcome-variation coding protocol. Hungary is supplemental because its 2026 turnover lies beyond the principal V-Dem 2026 data window used to define the initial set.

The principal timing contrast is Nixon–McGahn, with Fast and Furious retained as a more complicated third seed episode.

## Structural chapters

The House/subnational chapter is retained because institutional-redistricting evidence supplies a defensible causal bridge from rule design to partisan bias/competitiveness and because state cases can trace downstream control of accountability institutions.

Electoral design is retained only as structural reinforcement. Formal voting properties and STV implementation feasibility are kept separate from downstream democratic-resilience claims.

## STV engineering result

The separate private STV repository analyzed 1,049 Scottish elections from 2012–2022. A 4-rank cap changed 14 winner sets; 5 changed 7; 6 changed 1; 7 and 8 changed none. Portland 2024 provides a six-column U.S. implementation case but is source-censored above rank 6. These results are engineering evidence only: the absence of winner-set changes under a tested ranking cap must not be interpreted as evidence that STV improves democratic resilience. The pinned-source pipeline, expanded regression tests, complete outputs, and source checksums were revalidated successfully in GitHub Actions run 10 on 2026-10-03.
