# Methodology

## Purpose

This repository supports mechanism-centered research for *Strong Enough to Govern*. The unit of analysis is not simply an institution or reform label but a causal chain: authority/resource control → consequential chokepoint → delay/discretion/secrecy/impunity/coercion-retaliation → affected accountability function → practical effect → reversibility → redundancy/dependency.

## Accountability functions

Coding distinguishes five functions: detection; adjudication/authorization; implementation/compliance; sanction; replacement/restoration. These functions may occur sequentially, in parallel, recursively, or not at all in a given episode.

## Entrenchment terminology

An entrenchment mechanism is coded by observable institutional effect: whether public authority materially weakens timely independent correction or reversal. Personal self-entrenchment is a narrower proposition requiring additional evidence of incumbent-preservation purpose.

## Comparative cases

Case selection is defined before interpretation. Cases should include variation in attempted capture and outcome, including sustained erosion, successful resistance, difficult restoration, and negative/deviant cases. Each case is coded using the same variables and timeline. Comparative evidence tests mechanisms; it does not directly estimate U.S. causal effects.

## Durability

Safeguards are evaluated on two separate dimensions:

1. cumulative threat-level resilience under escalating combinations of executive pressure, legislative alignment, administrative control, weakened/slow judicial enforcement or noncompliance, and coercive/implementation pressure;
2. individual dependency sensitivity to failure of one critical dependency such as appropriations, courts, state cooperation, records/information, career personnel, or coercive compliance.

Nominally distinct safeguards are not treated as independent backups when they share a common-mode failure source.
